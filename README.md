# 🎮 Guess Number Game

A simple **number guessing game** built with **Python and Tkinter**.

## ✨ Features

* Player name input
* Three difficulty levels
* Different number of attempts for each level
* Random number generation
* Hints after each incorrect guess
* Game result logging
* Option to play again

## 🎯 Difficulty Levels

| Level  | Number Range | Attempts |
| ------ | -----------: | -------: |
| Easy   |         1–20 |        4 |
| Medium |         1–50 |        5 |
| Hard   |        1–100 |        7 |

## 🛠️ Technologies

* **Python**
* **Tkinter**
* **Random module**

## 🚀 How to Run

Make sure Python is installed on your computer.

Then run:

```bash
python guess_number_game.py
```
